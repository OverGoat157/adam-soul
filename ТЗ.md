Техническое задание на разработку сайта-каталога с интеграцией с 1С:УНФ
Раздел 1. FRONTEND (визуальная часть)
Цель: разработать адаптивный сайт-каталог, отображающий актуальные товары из 1С:УНФ в виде витрины без оформления заказов.
1. Главная страница каталога
- Меню-категорий: динамически подтягиваются из 1С как категории номенклатур.- Пример категорий: Костюмы тройки, Рубашки, Трикотаж, Пальто и т.д.- Меню отображается на всех страницах.
2. Страница категории товаров
- Заголовок и подзаголовок категории.- Сетка товаров: 3 карточки в ряд (десктоп).- Каждая карточка: фото, название, цена.- По клику — поп-ап с детальной карточкой.
3. Карточка товара (всплывающее окно)
- Название, артикул, цена.- Основное фото из 1С + возможность добавлять фото вручную.- Размеры — выпадающий список с остатками.- Описание — из 1С.
4. Общие требования к фронту
- Адаптивность (десктоп/мобайл).- Понятный и легкий для восприятия UI, фавикон, читаемый шрифт (например, Montserrat в его вариантах или HeliosExtc.- Минимизация багов, лёгкий код.
5. Этапы работ по frontend 
- Главная страница с меню категорий 
- Шаблон страницы категории 
- Карточки товаров в категории 
- Поп-ап карточки товара
- Выпадающий список размеров 
- Вывод описания, фото, артикула 
- Доп. фото через админку Django 
- Мобильная адаптация 
- UI-финализация 
- Тестирование фронта 
Раздел 2. BACKEND (интеграция с 1С:УНФ через CommerceML)
1. Источник данных
- Платформа: 1С:УНФ (Фрэш)- Интеграция: CommerceML 2.0- Доступ предоставляется разработчику
2. Передаётся из 1С на сайт:
- Категории изделий (категории номенклатуры)- Название изделия, артикул, цена, описание- Характеристики (размеры)- Остатки по размерам и общий остаток- Фото
3. Частота обмена
- Автоматическая синхронизация каждые 15 минут- Возможность ручного запуска
4. Функции личного кабинета администратора сайта
- Список товаров с фильтрацией- Ручное редактирование: фото, описание, видео- Логи выгрузки, кнопка ручного обновления- Возможность временно скрыть товар с сайта- Добавление индивидуальных карточек вручную
5. Тестирование и устойчивость
- Проверка точности соответствия данных- Обработка ошибок и система логирования- Быстрое устранение багов
6. Этапы работ по backend
- Настройка подключения CommerceML 
- Парсинг категорий и меню 
- Парсинг номенклатуры, фото, артикула 
- Отображение остатков и размеров 
- Описание и цены в карточке 
- Автообновление каждые 15 минут 
- Разработка ЛК администратора 
- Редактирование карточек вручную 
- Система логов и ошибок 
- Тестирование и отладка
